### 瓶颈 0（最阻断）：判据度的是「形状」，不是「正确」

同一批 285 题 dev 可判分母，四条实测：

| 输入 | 通过 | 读法 |
|---|---|---|
| 生产链路现状 | 198/285 = 69.47% | 真实系统 |
| **只把「问句锚点 + 正确 gold」拼成一句**（零检索零证据） | **285/285 = 100.00%** | 形状 oracle |
| 同句式但 gold 换成随机错误实体名 | 1/285 = 0.35% | 错名地板 |
| **答案直接等于 gold 原文** | **171/285 = 60.00%** | **低于生产** |

- ⇒ **dev 分数与答案正确性不是单调关系**，任何只学句式的改动都能推到 100%。
