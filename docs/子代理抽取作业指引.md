# 子代理抽取作业指引（L3，v2）

你是本次抽取的执行者。**不得调用任何模型接口**：不许 curl、不许碰 127.0.0.1:7863、不许碰 Ollama/11434、不许读 `.env` 或任何密钥。抽取由你自己完成。

## 输入与输出（路径由调度者给你的 tag 决定）

- 规则与受控词表（先读，冲突以它为准）：`<仓库根>\data\arkrag\agent_inbox\batch.system.md`
- 任务文件：`<仓库根>\data\arkrag\agent_inbox\<tag>.jsonl`（每行一个 JSON：`chunk_id` / `content_key` / `user_prompt`）
- 输出文件：`<仓库根>\data\arkrag\agent_outbox\<tag>.jsonl`

输出**每行一个 JSON 对象**，与任务行一一对应、顺序一致，不包数组、不加 markdown 围栏：

```
{"chunk_id":"逐字照抄","entities":[{"name":"阿米娅","type":"角色","aliases":["leader"],"desc":"罗德岛的领导者"}],"relations":[{"source":"阿米娅","relation":"交谈","target":"凯尔希","evidence":"凯尔希，你怎么在这里","confidence":0.8}]}
```

## 硬性判据（违反任何一条，这块就是废品）

1. `type` 只能取：角色 / 组织 / 地点 / 物品 / 概念 / 事件。取不到就丢弃该实体。
2. `relation` 必须**逐字来自** `batch.system.md` 里的封闭关系表。表里没有就丢弃该关系，禁止自造。
3. `evidence` 必须是该块正文（`user_prompt` 里两道 `---` 之间）的**连续原文子串**，≤40 字，不得改写、不得概括。写出前逐条做字符串包含自检；自检不过就改证据或丢该关系。
4. `source` 与 `target` 必须都出现在同一条记录的 `entities` 里，且名字逐字一致。
5. `confidence` 是 0.5–0.95 的数字。
6. 优先建边：对话往来用「交谈」，同行用「同行」，下令/指派用「指挥」，效忠某人某势力用「效忠」，成员身份用「隶属」，作战用「敌对/交战/冲突」。但**错误的节点比缺失的节点危害大得多**仍然压过建边冲动：原文没写的关系一律不建。
7. 禁止成为实体：代词（我/你/他/她/它/我们/你们/他们/某人/对方/别人/大家/自己）、掩码说话人（`？？？`）、**任何无专名的职业/身份/群体泛称**（这条是判据不是举例：士兵 众人 先生 女士 医生 平民 队员 干部 村民 游客 佣兵 司机 驾驶员 刺客 杀手 盗贼 难民 囚犯 奴隶 仆人 管家 秘书 助理 记者 商人 工匠 水手 船长 警察 探员 特工 长官 首领 头目 队长 哨兵 卫兵 警卫 守卫 军官 敌人 对方 同伴 伙伴 同僚 群众 市民 居民 百姓 学生 教师 研究员 科学家 学者 观众 路人 黑衣人 白袍人 神秘人 等一律不收；带通名的「整合运动成员A」「莱茵实验员B」「乌萨斯军警」也不收，只收其中的组织本体），以及编号与代码（`LC0073458`、`ZOOT-SYS-INIT`、`VI03`、任何全大写字母数字串）。同一句里与该编号或泛称同现的**专名照常抽**。判据是「这个名字本身能不能区分唯一个体」：不能区分就不收。
8. 「事件」只收有专名的重大事件（如切尔诺伯格事变），不收动作句。
9. 实体名必须是名字，不能是描述性短语，禁止整句当名字。
10. `aliases` 不得包含规范名自身。
11. `desc` 一句话说清它是什么，不复述剧情。
12. 确实无内容的块，仍要输出该行，`entities` 与 `relations` 给空数组。**不许跳行，不许凑数。**
