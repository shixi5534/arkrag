## 4. 「问标题」的问句模板（Lead 允许的只读工作，已做）

21 题的问句只有 **2 个稳定模板 + 2 道特例**：

### 模板 A（11 题，答案泄露在问句里）
```
在剧情《{TITLE}》的正文里，出现了这样一句话：「{QUOTE}」。这句话出自哪个文本块？请给出该块的标题。
```
触发词：`在剧情《…》的正文里` + `请给出该块的标题`
**注意：`{TITLE}` 就是答案本身。** 这个模板的存在意味着 gold 设计上把答案给了问句。

### 模板 B（8 题，答案不在问句里）
```
下面这段原文来自哪一段剧情？「{QUOTE}」请回答该段的标题。
```
触发词：`下面这段原文来自哪一段剧情？` + `请回答该段的标题`

### 特例（2 题）
- `q-dr-000047`：「X」对「Y」处于哪种关系？ → 不是标题题
- `q-tc-000007`：…分别被描述为「A」和「B」。这两条记录应如何理解？ → 不是标题题

**稳定触发词集合**：`请给出该块的标题` / `请回答该段的标题` / `出自哪个文本块` /
`来自哪一段剧情`。两个模板都以「标题」作为答案类型，与 `answer_form == needs_metadata`
（判据：`acceptable_answers` 含 `#` 或 `/`，或问句含「请给出该块的标题/请回答该段的标题」）完全一致。

> **给 P3 的建议（不是结论）**：模板 B 的 8 题才是「读 title」这个能力的干净样本
> （答案不在问句里）。模板 A 的 11 题可以当「问句回显」能力的样本，两者应分开度量，
> 否则「问句泄露」会把增益虚高约 1.8 倍（0.2333 vs 0.1967）。
