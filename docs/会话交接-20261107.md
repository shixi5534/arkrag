## 5. 判据（`src/arkrag/judge.py`，唯一实现）

```python
from arkrag import judge
judge.judge_answer(category, answer_text, item, *, question=None, chapter_texts=None)
# -> {"pass": True/False/None, "reason": str}
judge.SCORABLE_CATEGORIES == ('single_chunk','alias','direct_relation','multihop','cross_chunk')
judge.STRUCTURAL_CATEGORIES == ('time_conflict','negative_abstain','adversarial')
```

- `single_chunk` / `alias`：gold 或任一 `acceptable_answers` 子串命中任一断言。
- `cross_chunk`：`gold ⊆ got` → 额外章节逐个查 `chapter_texts[ch]` 必须含实体名 → `len(extra) <= len(gold)`。**不传 `chapter_texts` 显式降级** `reason="extra_chapters_unverified"` 并判 False。
- `direct_relation`：某一条断言同时含**全部**问句锚点 + gold。
- `multihop`：gold 与**每一个**锚点**各自**有一条断言共现，且 gold 不是锚点。
- 结构类 → `None`；空答案 → `False, reason="empty"`（拒答不算答对）。

`_CHAPTER_SPLIT = r"[、,，/／\s]+"` —— **必须含 `\s`**（gold 里出现过 `act33side main_ep14` 空格分隔）。

**三套被否证过的错口径（别再犯）**：
1. "答案含 gold 串" —— MAX_CLAIMS 5→12 会假涨 15 题，多出来的是撞高频专名（`隶属` 出现在 102/350 题答案里）。
2. cross_chunk 超集判据 —— 大预算下虚增 3–5pt（12000 档 236 vs 225）。
3. 问句自带答案 —— single_chunk 76 题里 46 题 gold 就写在题干书名号里，零检索抄标题就过 46/76（16.14%）。

**消费者**：`scripts/eval_answer_quality.py`（`--split dev|holdout|clean|all`、`--token-budget`、`--json`）。
⚠ 其余 `eval_*.py` 仍各写一份判据，**同一判定写多处的问题未除**。

## 8. 环境坑（会重复踩）

1. **控制台是 GBK/cp936**：Python 打印 `−`(U+2212)、`⇒`、`→` 会 `UnicodeEncodeError`。脚本打印一律用 ASCII `-`；读中文加 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8", errors="replace")`。
2. **改文件必须写 `.py` 临时脚本再执行**，不要 `py -3 -c` 内联（转义会吃掉反引号、`\n` 会变真换行）。
3. **CRLF 会被写坏**：`write_text(newline="")` 会把全文折成 LF-only。改完必须机检 `raw.count(b"\n") - raw.count(b"\r\n") == 0`。已发生三次。
4. **`ExtractiveAnswerer.__init__` 的 `max_claims: int = MAX_CLAIMS` 是定义时绑定**：改模块常量不会影响已构造实例。测参数必须 `pipe["answerer"].max_claims = N`。
5. **断言文件的 `subject_id`/`object_id` 是实体 ID 不是名字**：直接按名字比会全表 0 命中，必须先 `{e["id"]: e["name"]}` 映射。
6. **`gold-v1.json` 的题在 `items` 不是 `questions`**；`gold-v1` 无 `split`/`origin`；`gold-v2` 有。
7. **`verify_citations` 返回值没有 `failures` 键**，是 `out["verification"] = {"passed","rejected","problems"}`；引用本体在 `answer["citations"]`。
8. **装大包先试清华源**：`-i https://pypi.tuna.tsinghua.edu.cn/simple`（229MB 的 onnxruntime-gpu 从 10+ 分钟卡死变成 17 秒）。
9. **`build_context` 的 `direct()` 读 `s["channel"]` 不是 `s["source"]`**，键写错当场 KeyError。
